FOR MERI JAAN - BIRTHDAY WEBSITE WITH PHOTOS

1. Extract this ZIP to a folder.
2. Open the extracted folder in VS Code.
3. Open index.html with Live Server.
4. Scroll through the page. Try the reason cards, birthday wish buttons, gift and photo gallery.
5. Keep the photos folder beside index.html. Do not move or rename it.

This is a static website. It works locally without a paid service. To share it publicly, upload the entire extracted folder (index.html AND photos folder) to a static website host.
